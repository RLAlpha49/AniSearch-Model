    Using Different Models¶

    python src/main.py search --type anime --query "Space western with bounty hunters" --model "cross-encoder/ms-marco-TinyBERT-L-2"

    python src/main.py search --type anime --query "Space western with bounty hunters" --model "cross-encoder/ms-marco-MiniLM-L-6-v2"

    python src/main.py search --type anime --query "Space western with bounty hunters" --model "cross-encoder/ms-marco-MiniLM-L-12-v2"

    Including Light Novels in Manga Search¶

    python src/main.py search --type manga --query "Isekai adventure with game mechanics"

    Query Variation Process¶

    The search system improves results by generating variations of the original query:

    flowchart LR
    A[Base Queries] --> B[Create Empty Variations List]
    B --> C[Add Original Queries]
    C --> D[Select Random Templates]
    D --> E[Format Templates with Queries]
    E --> F[Return Combined Variations]

    style A fill:#e1f5fe,stroke:#0288d1
    style F fill:#e8f5e9,stroke:#4caf50
    Press "Alt" / "Option" to enable Pan & Zoom

    For example, a simple query like "time travel" might be expanded to:

    • time travel
    • Looking for anime about time travel
    • I want to watch anime with time travel
    • Find me anime where time travel

    This makes the search more robust to different ways of expressing the same information need.
